# 藏易阁 · 第一卷

以《易》为锁，以知为钥。这是一款周易主题的 3D 密室逃脱，面向成年玩家。你扮演一只灵龟，龟背上是洛书九宫。你在一座古老的藏书阁里醒来，四面的门都锁着，而阁主把每一道门锁都设计成了一段易理。

> 本目录是独立项目，自带 Three.js、服务器和构建脚本，不引用、也不修改仓库里的其他游戏（易境 · 爻爻、Codex 版易境）。

## 怎么玩

**不想装任何东西**：下载 `release/藏易阁.html`，双击用浏览器（Chrome / Edge / Safari）打开即可。

开发者：

```bash
cd cangyi
npm install
npm start          # http://127.0.0.1:8530
npm run build      # 打包为单文件离线版 dist/藏易阁.html
npm run verify     # 自动验证（需先 build）
```

| 操作 | 方式 |
|---|---|
| 行走 | WASD / 方向键；按住 Shift 快走 |
| 看四周 | 按住鼠标拖动；第三人称下可用滚轮调远近 |
| 互动 | 点击物品。离得远时，团子会先自动走过去再互动；也可以按 E 与身前的物品互动 |
| 走到某处 | 点击地面 |
| 切换视角 | V，或右上角的视角按钮。第一人称觉得晕，就切回第三人称 |
| 易笔记 / 问书灵 | N / H |

防晕设计：
- 默认使用第三人称；
- 第一人称下镜头不随走路晃动，屏幕中间有准星；
- 视野宽度和转动灵敏度可以在「设」里调。

## 第一卷 · 三间屋

| 屋 | 学到的知识 | 机关 |
|---|---|---|
| 门厅 · 卦画 | 阴爻和阳爻；卦从下往上读；《八卦取象歌》 | 四屉柜，抽屉上分别标着震、艮、兑、巽。点击每条爻切换阴阳，自下而上排对就能打开；四个抽屉全开后，柜顶出现钥匙 |
| 先天室 | 先天八卦的次序与方位；《说卦传》"天地定位，山泽通气，雷风相薄，水火不相射" | ① 八角台上的八块卦牌放乱了，点两块可以交换，要排成先天方位。台外地上标着八个方位（字始终朝向镜头），鼠标悬停卦牌也会提示它现在在哪个方位；② 台心升起一只铜箱，转盘锁的谜面是"以先天之数，记雷、风、水、火"，对应 4563 |
| 后天室 | 后天八卦方位；《说卦传》"帝出乎震……成言乎艮" | 屋里八盏铜灯不写字，要借罗盘辨认方位，按原文次序（东→东南→南→西南→西→西北→北→东北）依次点亮，点错就全部熄灭 |

- **灵龟**有五种颜色可选：青玉、墨玉、白玉、赤金、琥珀。龟甲上是洛书九宫，"戴九履一，左三右七，二四为肩，六八为足，五居中"，奇数画白点，偶数画黑点。每解开一处机关，就按 1、2、3……的顺序点亮一格。
- **书灵**负责给提示，每道谜题分三级：先点拨方向，再告诉方法，最后给出答案。
- **易笔记**会记下读到的每一段知识，并注明出处。
- **存档**：进度、机关状态和所在位置都会自动保存，刷新页面后可以接着玩。

## 考据

数据见 `src/lore.js`。

| 内容 | 出处 |
|---|---|
| 爻位名称（初、二……上） | 《周易》经文爻题 |
| 八卦取象歌 | 朱熹《周易本义》卷首 |
| "天地定位……八卦相错"、"帝出乎震"一节及各卦方位 | 《周易·说卦传》 |
| 先天次序（乾一……坤八）与先天方位（乾南坤北、离东坎西……） | 北宋邵雍的先天学，图式见朱熹《周易本义》卷首《伏羲八卦次序》《伏羲八卦方位》。游戏中明确标为"宋人之说"，不当作经文 |
| 坤居西南 | 《说卦传》原文没有直接写出坤的方位，这是后世通行的理解，游戏中已单独注明 |
| 洛书九宫的口诀与配数 | 宋人图书之学（见朱熹《易学启蒙》）。游戏里只用作龟甲上的图案，后续"图书室"会专门讲解 |

## 验证

`npm run verify` 用真实鼠标点击 3D 物体，打通三间屋。截图和报告保存在 `docs/verification/`。
