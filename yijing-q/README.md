# 易境 · 爻爻（独立新版）

可爱、Q 弹的小团子们穿过八卦之境。当前是 v0.2，已完成三境：**坎（水）→ 离（火）→ 水火既济**。

> 本目录完全独立：自带 Three.js、自己的服务器和构建脚本，不引用也不修改仓库根目录的原版（Codex 版《易境 · 雨后通途》）任何文件。原版可以随时照常使用。

## 怎么玩

**不想装任何东西**：下载 `release/易境-爻爻.html`，双击用浏览器（Chrome / Edge / Safari）打开即可。

开发者：

```bash
cd yijing-q
npm install
npm start          # http://127.0.0.1:8520
npm run build      # 打包为单文件离线版 dist/易境-爻爻.html
npm run verify     # 自动验证（需先 build）：不瞬移，真实走跳打通三境 + 截图
```

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动（走路自动蹦跳） | WASD / 方向键 | 左下摇杆 |
| 跳 / 二段跳 | 空格（空中再按一次） | 「跳」 |
| 互动（读碑、点火、拿 / 放爻块） | E | 「E」 |
| 水火变身（第三境） | F | 「变」 |
| 转镜头 / 远近 | 拖动、Q R / 滚轮 | 右侧拖动 |
| 选关 | 右上角「关」，或标题页"直接选关" | 同左 |

## 内容

### 四个角色（能力完全一样，只有外形和手感不同）

| 角色 | 外形 | 手感 |
|---|---|---|
| 爻爻 | 玉质果冻团子，头顶一片玉叶 | 弹得快，回弹利落 |
| 糯糯 | 糯米玉兔，长耳朵 | 软软的，能拉很长，回弹慢半拍，耳朵会甩 |
| 麟麟 | 琥珀软糖小麒麟，有鹿角和卷尾巴 | 有点硬的 Q，落地会抖两下 |
| 鲤鲤 | 锦鲤果冻，头顶丹顶，有鳍 | 像小鱼一样扑腾，尾巴会摆 |

所有动作都靠弹簧模拟，没有骨骼动画。每个角色肚子上都有当前这一境的卦象。

### 三境

| 境 | 核心玩法 | 新机制 |
|---|---|---|
| 第一境 · 习坎 | 跳上三座爻台切换阴阳，排出坎卦 ☵ | 浮石、木筏、云垫、二段跳高台 |
| 第二境 · 继明 | 从火塘取火（有时限），点燃或盖灭火台，排出离卦 ☲ | 升降台、横移石，地图连成一圈 |
| 第三境 · 既济 | 把 3 块阳爻、3 块阴爻搬上鼎山，按"当位"放进初～上六个爻座；之后"初吉终乱"，要限时化解三处乱子 | 水火变身、搬运（阳爻重，走得慢、不能二段跳）、小怪"乱乱"、火墙、冰封、逆流而上的瀑布、蒸汽口、石灯与石莲花、隐藏的未济祭坛 |

第三境的体量约等于前两境之和，地图分上下两层：下层是火域，上层是水域，中间是鼎山。

### 模式与评价

- **普通**：落水回到最近站稳的地方，不限时。
- **挑战**：每境限时；落水回到本境起点；火种只燃 18 秒；终乱只给 60 秒。
- **三颗星**：通关、本境 6 枚爻玉全收、本境不落水。最佳成绩保存在本机。

### 音乐（全部由代码现场合成，用五声音阶）

| 场景 | 调式 |
|---|---|
| 标题 | 宫调 |
| 坎 | 羽调 |
| 离 | 徵调 |
| 既济 | 羽调与徵调交替 |
| 终乱 | 快节奏的商调 |

- 推进时音乐会逐层加入笛子和打击乐。
- 拿到爻玉、解开卦象、过关都有对应的小乐句。
- 音乐和音效各有独立开关。

### 图鉴（11 张入门知识卡）

- 卦：坎、离、既济、未济
- 知识：爻位、当位、五音
- 角色：爻爻、糯糯、麟麟、鲤鲤

每张卡包含拼音、一句白话解释、口诀或要点、原文（注明出处）和"在游戏里"的对应。卡片随游戏进度解锁，记录保存在本机。

## 考据

数据在 `src/lore.js` 和 `src/codex.js`。

| 内容 | 出处 |
|---|---|
| 八卦取象（坎为水、离为火……） | 《周易·说卦传》。原文分见各节，游戏里没有把它们当成连续的一段话引用 |
| 坎中满、离中虚 | 朱熹《周易本义》卷首《八卦取象歌》 |
| 习坎、离、既济的卦辞 | 《周易》经文 |
| "刚柔正而位当也""初吉终乱" | 既济《彖传》、卦辞 |
| "水洊至，习坎""明两作，离""水在火上，既济。君子以思患而豫防之""火在水上，未济" | 《象传》 |
| "物不可穷也，故受之以未济终焉" | 《序卦传》 |
| 后天八卦方位 | 《说卦传》"帝出乎震"一节；坤西南为后世通行之说，游戏中单独注明 |
| 五音配四季与五行（孟冬"其音羽""盛德在水"，孟夏"其音徵""盛德在火"） | 《礼记·月令》 |
| "君子比德于玉焉：温润而泽，仁也" | 《礼记·聘义》 |
| "麟者，仁兽也" | 《春秋公羊传·哀公十四年》 |
| "月中何有？白兔捣药" | 晋·傅玄《拟天问》 |
| 锦鲤 | 卡片明确写"无古籍引文" |

- 傅玄《拟天问》原书不传，这句是流传很广的引文，正式发布前建议再核对一下所据的版本。
- 游戏玩法本身都是原创规则，游戏里都标为"原创"，不冒充古籍中的占法。这包括：爻台切换阴阳、点火记为阳爻、爻块放进爻座、终乱时要化解的三处乱子等。

## 验证结果

`npm run verify` 共 55 项检查，全部通过。报告见 `docs/verification/verify-report.json`，日志见 `verify.log`，截图在 `docs/verification/`。

验证方式是：**不瞬移，按真实路线自动走、跳、变身、搬运，打通三境**。覆盖的内容有：
- 四个角色的手感与能力一致性；
- 音乐的调式切换；
- 图鉴解锁；
- 挑战模式；
- 第三境"放错爻位会被拒绝"；
- 终乱限时化解；
- 未济隐藏祭坛；
- 手机触屏摇杆；
- 服务器版和离线单文件版两种入口。

物理用固定步长推进，所以结果不受机器帧率影响。

**没有验证到的：**
- 这台云端机器没有显卡，没法测真实的流畅度、手感和音乐听感，需要在你自己的电脑或手机上试玩确认。
- 音色是代码合成的古筝、笛子音色，比不上真乐器录音。
