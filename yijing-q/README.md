# 易境 · 爻爻（独立新版）

一只玉质果冻团子「爻爻」，穿过八卦之境。这是 v0.1，先做了两境：**坎（水）** 和 **离（火）**。

> 本目录完全独立：自带 Three.js、自己的服务器和构建脚本，不引用也不修改仓库根目录的原版（Codex 版《易境 · 雨后通途》）任何文件。原版可以随时照常使用。

## 运行

```bash
cd yijing-q
npm install
npm start          # http://127.0.0.1:8520
npm run build      # 打包为单文件离线版 dist/易境-爻爻.html，双击就能玩
npm run verify     # 自动验证（需先 build）：真实走跳打通两境 + 截图
```

## 玩法

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动（走路自动蹦跳） | WASD / 方向键 | 左下摇杆 |
| 跳 / 二段跳 | 空格（空中再按一次） | 「跳」 |
| 互动（读碑、点火、盖火） | E | 「E」 |
| 转镜头 / 远近 | 拖动、Q R / 滚轮 | 右侧拖动 |

每一境的规则：**先解开本境的卦象，再收集至少 3 枚爻玉（每境 6 枚），卦门就会亮起**，走进去就进入下一境。

- **第一境 · 习坎**：三座爻台从低到高排成台阶，分别对应初、二、三爻。跳上爻台可以切换阴阳，排成坎卦 ☵ 后，水下的石桥会升起。地图上有浮动石墩、往返木筏、云垫弹跳和需要二段跳的高台。
- **第二境 · 继明**（黄昏）：从火塘取火（火种 28 秒后熄灭，落水也会熄灭），送去点燃火台；按 E 可以盖灭火台。目标是排成离卦 ☲。地图上有升降台、横移石，还有一条下山石阶，整张地图连成一圈。
- 通关后显示后天八卦方位图，已通过的境会点亮。

## 美术

- **主角**：玉质果冻团子。身体半透明，带清漆高光、边缘光、内芯和腮红，头顶一片玉叶，肚子上刻着当前境的卦象。
- **动作**：压扁、拉长和前后左右的晃动全部用弹簧模拟，没有骨骼动画，所以不存在"走路姿势别扭"的问题。走路就是一蹦一蹦地前进；落地压扁，起跳拉长；会眨眼、会呼吸；拿到爻玉时叶子会摇。
- **场景**：浮岛群、动态水面、渐变天空、水墨远山、竹林、松树、石灯笼、草地和花，全部由程序生成，不需要外部贴图或字体，可以离线运行。

## 考据

所有引文都注明了出处，详见游戏内「卦」按钮和「关于考据」，数据在 `src/lore.js`：

- 八卦取象：《周易·说卦传》，坎为水、离为火等。这八句在原文中分见各节，游戏里没有把它们当作连续的一段话引用。巽一节原文作"巽为木，为风"。
- 卦形口诀：朱熹《周易本义》卷首《八卦取象歌》，如"坎中满""离中虚"。
- 卦辞和《象传》（大象）原文，例如"水洊至，习坎""明两作，离"。
- 方位：《说卦传》"帝出乎震"一节（后天八卦方位）。坤西南为后世通行之说，游戏里单独注明了这一点。
- 卦画自下而上读，爻位依次称初、二、三。
- **爻台切换阴阳、点火为阳等都是本作的原创规则**，游戏内也明确标为"原创"，不冒充古籍中的占法。

## 验证结果

`npm run verify` 的结果：30/30 通过，报告在 `docs/verification/verify-report.json`，日志在 `verify.log`。

验证的方式是：**不瞬移，按真实路线自动走、跳，打通两境**。覆盖的内容有：
- 解卦、收集爻玉、穿过卦门；
- 弹跳形变、二段跳、落水重生；
- 服务器版和离线单文件版两种入口；
- 手机尺寸下的触屏摇杆。

物理用固定步长推进，所以结果不受机器帧率影响；在云端没有显卡的环境里也能通过。截图在 `docs/verification/`。

要说明的是，这台云端机器没有显卡，没法测真实的流畅度和手感，这些需要在你自己的电脑或手机上试玩确认。
