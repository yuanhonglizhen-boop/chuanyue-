      怎么玩

      • W A S D / 方向键：移动（走路会自己蹦蹦跳跳）
      • 空格：跳；空中再按一次：二段跳
      • E：读石碑、点燃或盖灭火台、拿起 / 放下爻块
      • F（触屏「变」）：第三境的水火变身：原形 → 水态 → 火态
      • 第四境在水下：按住 空格（触屏按住「跳」）往上游，松开慢慢下沉；到了九四，空中连按两下跳（或 F / 触屏「震」）向下猛砸
      • 拖动画面 / Q R：转镜头；滚轮：远近
      • 掉进水里会回到最近站稳的地方（挑战模式回到本境起点）
      • 每境：先解开卦象，再收集至少 3 枚爻玉，卦门就会亮起
      • 三颗星：通关、六枚爻玉全收、本境不落水
      • 「鉴」：图鉴，收集卦象和知识卡
